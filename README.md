# MistWalker

MistWalker is a tactical battlemap generator, fog-of-war campaign board, and D&D AI Chatbot oracle. It is designed to assist Dungeon Masters in managing campaigns, particularly those set in environments like Keys from the Golden Vault or Vecna: Eve of Ruin.

## Features
- **Tactical Battlemap Generator:** Create and visualize encounter maps.
- **Fog-of-War Campaign Board:** Manage player visibility and exploration on the fly.
- **D&D AI Chatbot Oracle:** An AI co-pilot for 5e RAW rules and DM support.

## Technologies
- **Frontend:** React, Vite, TypeScript, Tailwind CSS, Konva (for canvas).
- **Backend:** Node.js, Express, Firebase Firestore, Firebase Authentication.
- **AI Integration:** Google Gemini API.

## Getting Started
1. **Prerequisites:** Node.js installed.
2. **Setup:**
   - Clone the repository.
   - Run `npm install` to install dependencies.
   - Configure your `.env` file based on `.env.example`.
3. **Running the App:**
   - Run `npm run dev` to start the development server.
4. **Building:**
   - Run `npm run build` to create a production build.
